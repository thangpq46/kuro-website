# Kuro: Private Diary Journal — website

Static site for the Android app **Kuro: Private Diary Journal**
(`com.shura.studios.diary`), published with GitHub Pages.

| Page | Purpose |
|---|---|
| `index.html` | App home page |
| `privacy.html` | Privacy policy |
| `terms.html` | Terms of service |
| `assets/` | App icon, theme artwork and icons used by the pages |

No build step and no dependencies: plain HTML, CSS and a little vanilla JavaScript.
Open `index.html` in a browser to preview, edit the file, refresh.
